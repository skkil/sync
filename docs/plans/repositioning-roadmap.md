# Plan: SYNC 리포지셔닝 — "AI가 인용하는 팀 검증 지식 레이어"로 전환

## Goal

기존 방향(Stack Overflow류 Q&A 포럼을 한국어로 복제)을 중단하고, 아래 시장 분석
리포트의 Option A("팀의 검증된 답변 레이어, AI가 인용 가능")를 따른다.

> 근거 요약: Stack Overflow 공개 포럼 질문량은 ChatGPT 등장 이후 구조적으로
> 붕괴(2025년 4월 기준 전년 대비 약 64% 감소, 2025년 12월 기준 전년 대비 78%
> 감소)했고, Stack Overflow 자체도 "Stack Internal"(Teams)과 MCP 기반 AI
> 그라운딩으로 전략을 옮겼다. 다만 Stack Overflow for Teams는 (1) 인당 과금이라
> 팀 성장에 불리하고, (2) 콜드스타트 문제가 구조적이며, (3) 채팅
> 수집(Ingestion)과 MCP 서버 기능을 Enterprise 등급에만 제공해 소규모 팀을
> 방치한다. 한국 시장은 "한국어 Stack Overflow가 없어서"가 아니라 "팀 내부 지식
> 캡처 마찰이 커서" 지식관리 도구 채택률이 낮다(한국 IT 기업 24% vs 선진국 평균
> 42%, Notion 인용). KakaoWork/Naver Works/JANDI/Slack으로 협업 도구가
> 파편화되어 있고, 독립형 한국어 개발자 커뮤니티(disquiet, Careerly)는
> 반복적으로 수익화에 실패해 인수합병으로 정리됐다. 반면 "AI가 사내 지식으로
> 답한다" 카테고리는 이미 Glean/Allganize/Upstage/Skelter Labs 등으로 매우
> 혼잡하므로, SYNC는 엔터프라이즈가 아니라 **소규모 기술 팀(5~50인)**, **채팅
> 네이티브 캡처**, **검증된 정답 우선**이라는 좁은 쐐기로 차별화해야 한다.

## 우선순위 원칙

- 새 기능은 다음 셋 중 하나에 직접 기여해야 한다: **(1) 캡처 마찰 최소화, (2)
  검증된 정답의 신뢰도, (3) AI(외부 도구)가 그 정답을 인용 가능하게 만들기.**
  여기에 기여하지 않는 기능은 보류.
- 포럼형 브라우징 UI, 마이크로블로그/블로그 포스트 타입은 신규 투자 대상에서
  제외(기존 자산은 유지하되 확장하지 않음).
- 실시간 presence/read-state 등 이미 구축된 인프라는 낮은 우선순위 — 유지만 하고
  추가 투자하지 않는다.

## 단계별 실행 순서 (리포트 "Staged next steps" 반영)

1. **0~3개월**: 0번(데이터 모델) → 1번 중 Slack 연동/캡처 루프 → 4번 MCP
   엔드포인트 최소 버전. 디자인 파트너 5~10팀(한국 스타트업) 확보.
2. **검증 기준**: 팀당 주당 검증된 답변 ≥5개가 안 나오면 캡처 루프 자체를 먼저
   고친다(2번 워크플로우 UX 우선 재검토).
3. **6~12개월**: 캡처+AI그라운딩이 리텐션에 효과가 있으면 1번의 KakaoWork/Naver
   Works 확장 + 5번 지식 격차 분석 라이트 버전 추가.
4. **전략 전환 기준**: AI 그라운딩이 2개 분기 내 디자인 파트너에게 측정 가능한
   가치를 보이지 못하면, 순수 캡처/요약(Option B)으로 축소.

## 명시적으로 하지 않을 것 (Option C/D 기각)

- **공개 한국어 개발자 커뮤니티(velog/OKKY류)를 핵심 제품으로 만들지 않는다** —
  disquiet, Careerly 등 선례가 수익화 실패로 귀결됨. 마케팅/유입 채널 정도로만
  취급.
- **한국 엔터프라이즈向 수직 지식 AI(Allganize/Upstage 경쟁)로 가지 않는다** —
  엔터프라이즈 세일즈, CSAP 등 보안 인증, 자본이 필요하며 SYNC 규모에서 승산이
  낮음.

## Caveats

- 한국 지식관리 도구 채택률 "24% vs 42%" 수치는 Notion 측 인용 통계로, 독립 기관
  검증 자료가 아니다 — 방향성 참고만.
- MCP/AI 그라운딩에 대한 소규모 팀의 실제 채택은 아직 검증되지 않은 가설이다. 위
  5번 계측 항목으로 조기에 확인해야 한다.
